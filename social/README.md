# Social drafts — handoff protocol

I write, I don't post. Every draft lands in `drafts/` as a numbered markdown file. PK reviews and posts manually from `@khaledalwaleed`. I never touch X, LinkedIn, or any posting API — no MCP, no browser automation for this.

## File format

`NN-slug.md`, each with an `## X` section and a `## LinkedIn` section. Char count noted under each — X's cap is 280.

## Hackathon rule this serves

Up to 5 X/LinkedIn post links can be submitted for the $500 × 2 social-engagement prize. Every post must tag:
- X: `@lablabai` and `@AlpacaHQ`
- LinkedIn: lablab.ai and Alpaca company pages
